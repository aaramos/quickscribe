**2.1.0** installs its own updates. When a newer version is out, the menu bar menu shows **Install version X and Relaunch**: one click downloads it, checks that it is signed by the same QuickScribe Release certificate as the copy you are running, replaces the app in Applications and reopens it. **What's New in version X…** next to it opens the release page. Nothing downloads until you click, and Install waits until you finish a dictation. If anything goes wrong, such as no network, a damaged download, a signature that does not match, or no permission to write to Applications, your installed app is left as it was and the release page opens so you can update by hand. Nothing else changed. Your settings, permissions and signature carry over.

**Install this one by hand**
Versions 2.0 to 2.0.2 can only tell you about a new version, so this update is the last one you install yourself:
1. Quit QuickScribe.
2. Download `QuickScribe.dmg`, open it and drag QuickScribe to Applications to replace the old one.
3. Open it. Because the app came from a download, macOS asks once more: go to System Settings > Privacy & Security and click Open Anyway.

From 2.1.0 on, updates are one click, with no Open Anyway step. macOS may still ask for Microphone or Accessibility after an update. If the hotkeys stop working, switch QuickScribe back on there, or remove it with the minus button and add it again. If you saved an API key, macOS may ask for your password so QuickScribe can read it: choose Always Allow.

Hold a hotkey, talk, let go, and clean text appears wherever you're typing. By default, speech recognition and cleanup both run on your Mac using Apple's own technology.

**Needs:** an Apple Silicon Mac on macOS 27. Turn on Apple Intelligence for AI cleanup; without it you still get dictation with a basic tidy-up.

**New install**
1. Download `QuickScribe.dmg`, open it and drag QuickScribe to Applications.
2. Open the app. macOS will block it the first time because it isn't signed with a paid Apple Developer ID. Go to System Settings > Privacy & Security and click Open Anyway.
3. Grant Microphone and Accessibility when asked, then quit and reopen the app.
4. Look for the icon in the menu bar. There's no window.

**Coming from version 1.0**
Install as above. Then quit QuickScribe Native and drag it to the Trash: the new app has a different name, so it doesn't replace the old one. If the hotkey doesn't work, open System Settings > Privacy & Security > Accessibility, remove the old entry with the minus button, add QuickScribe from Applications with the plus button, and reopen QuickScribe. Your mode and edited prompts carry over.

**What leaves your Mac:** a check with GitHub at launch and once a day that sends only the app name and version. When you choose Install, the app also downloads `QuickScribe.zip` from this release. Your words never leave your Mac unless you set a server address in Settings.

**Files**
- `QuickScribe.dmg`: for installing by hand.
- `QuickScribe.zip`: what the app downloads when you choose Install. You don't need to open it.

Only install it if you're comfortable running an app macOS can't verify. You can also build it yourself from the source code.
